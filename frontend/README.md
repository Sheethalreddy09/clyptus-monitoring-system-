# Clyptus Monitoring System - Frontend

React + TypeScript web client for the Clyptus Monitoring System, built with **Vite** and styled with **Tailwind CSS**.

---

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```

The application will be accessible at: [http://localhost:5173](http://localhost:5173)

### 3. Build for Production
```bash
npm run build
```

---

## 📁 Key Directories

- `src/pages/` - Application view pages (Dashboard, Projects, Tasks, Team, Activity, Chat, Calendar, Analytics)
- `src/components/` - Reusable UI widgets, layout navigation, modals, and tables
- `src/context/` - Authentication context (`AuthContext.tsx`)
- `src/services/` - Axios API client configuration (`api.ts`)
- `src/types/` - TypeScript interface and type declarations
